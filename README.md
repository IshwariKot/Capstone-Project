# Squardle

### For my Capstone project I have been working on a simple adaptation of the online game squardle. The game displays a grid of letters and the aim is to connect touching letters to build words. Finding all possible words on the grid wins the game.

### For this project, the grid will be a randomly generated 4x4 grid with a minimum of 5 vowels. All words must be in the UK Collins Scrabble Words 2021 list.

#### RULES:
- Words must be >= four letters
- Letters must neighbour horizontally vertically or diagonally. Your word must be abe to draw a path through the grid to connect letters.
- Each letter in a position on the grid can only be used once per word.
